```mermaid
flowchart LR
    A[Developer commit] --> B[CI pipeline<br/>GitHub Actions / GitLab CI]
    B --> C{Commit-level<br/>vulnerability scan}
    C -- findings --> D[AI remediation<br/>suggestions]
    D --> E[AI-driven code review<br/>Google Code Assist]
    C -- clean --> E
    E --> F{Compliance gate}
    F -- blocked --> D
    F -- approved --> G[Merge and deploy<br/>Terraform + Kubernetes]
    G --> H[Observability<br/>Prometheus · Grafana · OTel]
    H --> I[LLM agent launchpad<br/>AIOps incident response]
    I -.feedback.-> A
```
